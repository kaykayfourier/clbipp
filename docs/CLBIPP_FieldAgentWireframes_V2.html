The field agent experience,
screen by screen.

Every agent-facing screen rebuilt from the Field Agent Process Map (B01–B07). The agent is an independent partner who chooses jobs, navigates to them, and gets paid per pickup: accept or decline a nearby request, navigate to the customer, identify the battery, assess it, run the decision engine, present the offer, collect with proof, and hand batteries off to the hub in a batch. Same product, same design system as the Vendor app — mirrored economics.

!
Agent sees all, vendor sees little. The vendor app never shows recovered value, margins, or engine mechanics — only an estimated offer. The Field Agent app is the mirror image: full revenue and cost breakdown, net value, margin %, and the P_min / P_recommended / P_max price band. The one exception — the agent never sees the per-supplier margin override, only the resulting band.
₹
Independent partner, not salaried staff. The agent accepts or declines each job for a visible pickup fee, paid to an in-app wallet on collection. This payout is separate from the battery's purchase price shown to the vendor — the pricing-engine economics still route through the agent's screens unchanged.
